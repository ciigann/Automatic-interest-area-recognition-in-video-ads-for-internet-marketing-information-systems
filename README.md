# РАЗВИТИЕ ИНФОРМАЦИОННОЙ СИСТЕМЫ ПОДДЕРЖКИ СОВРЕМЕННОГО ИНТЕРНЕТ-МАРКЕТИНГА НА ОСНОВЕ АВТОМАТИЧЕСКОГО РАСПОЗНАВАНИЯ ОБЛАСТЕЙ ИНТЕРЕСА НА РЕКЛАМНЫХ ИЗОБРАЖЕНИЯХ В ВИДЕОПОТОКЕ

## Актуальность и проблематика

### Проблема:
- Отсутствие контекстного анализа;
- Высокие вычислительные требования.
  
### Актуальность:

- Отсутствие открытых решений;
- Потенциал для информационного маркетинга.

## Цель и задачи

### Цель: 

- Разработать информационную систему автоматического распознавания областей интереса на рекламных изображениях в потоковом режиме.

### Задачи:

- провести литературно-аналитический обзор;
- разработать модели;
- спроектировать систему;
- реализовать предлагаемое решение.

## Научная новизна

- Применение агентного метода И.В. Кашина для восстановления изображения с учётом контекста предыдущих кадров. Это позволяет алгоритмам машинного обучения непрерывно предсказывать области интереса, используя накопленную информацию для повышения точности анализа.

## Основные этапы

- Сбор данных айтрекинга и подготовка набора данных;
- Разработка библиотеки для предобработки изображений с применением агентного подхода для учёта контекста между кадрами;
- Построение модели машинного обучения для распознавания областей интереса;
- Объединение компонентов в единую систему, обеспечивающую автоматическое распознавание областей интереса на видеопоследовательности. 

## Критерии оценивания аналогов

Для решения задачи айтрекинга были выделены следующие критерии:
	1) Т – Точность;
	2) Н – Надёжность;	
	3) СВ  – Скорость вывода;
	3) ПИ – Простота интеграции;	
	4)  П – Производительность;
	5)  С – Стоимость/Доступность.
В результате сравнения аналогов был выбран прототип eyeGestures.

Для решения задачи агентного восстановления изображений с учетом контекста предыдущих кадров были выделены следующие критерии:
	1) СНК  – Способность к 
накоплению контекста;
	2) СиС – Сходимость и стаб.
	3) ВЭ  – Вычислительная эф.
	4) М – Масштабируемость;
	5) ИПС – Интерпретируемость промежуточных состояний.
В результате сравнения аналогов был выбран прототип агентный подход И.В. Кашина.

	2) СО – Скорость обучения;
	3) СВ  – Скорость вывода;
	4) Ин – Интерпретируемость;

## Инженерная реализация

Для реализации основного вычислительного модуля на C++ использовалась интегрированная среда разработки PyCharm 2024.2.1. Компиляция кода выполнялась из командной строки с применением инструментария MSYS (MinGW‑w64). Код соответствует стандарту «ISO/IEC 14882:2014(E) Programming Language C++» (C++14).
Для реализации модуля визуализации, интеграции с высокопроизводительным C++‑ядром и обработки видеопотока применялась та же среда разработки PyCharm 2024.2.1 с использованием языка Python версии 3.12.2.

Для оптимизации программы был сделан:
- Вынос критических вычислений в библиотеку на C++;
- Использование матричных операций для расчета коэффициента 𝐾𝑝(𝑟) одновременно для всех ячеек сетки;
- Использование параллельных вычислений для перемещения агентов и усреднения по ячейкам при формировании эталонной карты; 
- Выполнение нескольких шагов симуляции за один вызов функции C++;
- Организовано эффективное управление памятью: передача массивов в C++ по ссылке исключающая создание лишних копий.
